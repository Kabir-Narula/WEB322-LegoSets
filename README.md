# LEGO Sets — WEB322 Final Project

**WEB322 final project** — Seneca College, 2023.

Web application for browsing and managing LEGO set data with a Node/Express back end and interactive front end.

## Stack

Node.js · Express · HTML/CSS/JS

## Run locally

```bash
npm install
npm start
```
